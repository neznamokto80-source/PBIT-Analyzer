# Changelog

## [2.2.0] — 2026-10-26

### Добавлено

- **Поддержка PBIX** (семантическая модель Power BI):
  - кнопка «Выбрать PBIT/PBIX», фильтр диалога и drag-and-drop обоих форматов;
  - автоопределение формата по расширению и содержимому архива;
  - модель читается через `pbixray` 0.15.5 (read-only, без Power BI Desktop);
  - таблицы, столбцы, меры, вычисляемые столбцы/таблицы, DAX, Power Query (M),
    M-параметры, связи, RLS/OLS, перспективы, статистика хранения;
  - режим `on_disk` включается автоматически для файлов от 500 МБ (экономия RAM).
- **Модельный lineage для PBIX**: зависимости мер и вычисляемых столбцов,
  фокус на таблице (`S…`) или мере (`M…`). Визуальных узлов у PBIX нет.
- **Новые вкладки GUI в режиме PBIX**: Параметры M, Безопасность (RLS),
  Безопасность (OLS), Статистика хранения.
  Вкладки отчёта (Листы, Визуальные элементы, Условное форматирование) в PBIX скрыты.
- **Excel-отчёт PBIX**: новые листы Параметры M, Безопасность (RLS/OLS),
  Статистика хранения; отчёт `.pbit` не изменился.
- **CLI**: `run_cli.py` принимает `.pbix`, флаги `--on-disk` / `--in-memory`,
  код возврата `3` для неподдерживаемых/повреждённых файлов и PBIX без модели,
  `--self-test` для проверки сборки.
- **GUI `--self-test`**: создаёт окно без показа и проверяет импорт `pbixray`.

### Изменено

- Добавлена обязательная зависимость `pbixray==0.15.5` (бинарные декодеры
  `xpress8`/`xpress9`/`xmhuffman`), в GUI/CLI EXE она попадает вместе с hidden-import'ами.
- `ExcelReportGenerator` принимает набор листов и дополнительные строки статистики.
- В PBIX-режиме нет отдельных вкладок DAX и Power Query (M): это дублировало «Меры»,
  «Столбцы» и «Источники». Из Excel-отчёта PBIX удалены листы «DAX» и «Power Query»;
  ключи `dax` и `power_query` в результате анализа сохранены.
  Пустые разделы PBIX теперь показываются с пометкой «Нет данных», а не скрываются.
- Убраны вкладка GUI и лист Excel «Перспективы»: данные по-прежнему собираются
  (ключ `perspectives` в результате анализа), но в интерфейсе и отчёте не выводятся.
- Итоговое окно после анализа и после выгрузки в Excel показывает кнопки «ОК»
  и «Открыть Excel» — вторая сразу открывает созданный .xlsx.
- `build_exe.py` после сборки удаляет `build/`, `dist/` и `*.spec`: остаётся
  только готовый EXE в корне проекта (с `--no-copy`/`--dir` папка `dist/` нужна CI и сохраняется).
- `create_exe.bat` переписан как обёртка над `build_exe.py` (те же флаги);
  `tasks.bat` удалён.
- `.gitignore` пересохранён в UTF-8: правила для `dist/`, `build/`, `*.spec`
  и `__pycache__` снова применяются, `__pycache__` убран из индекса git.
- Сборка EXE явно исключает чужие Qt-биндинги (`PyQt5`, `PySide2`, `PySide6`).

### Исправлено

- Справка в собранном EXE снова показывает «Схема PBIT» и «Changelog»: документация
  ищется и в `sys._MEIPASS` (onefile-бандл), а не только на уровень выше него.
- Кнопки в диалогах (ОК, Открыть Excel, Закрыть в справке) были белыми на светлом
  фоне из-за глобального стиля `QPushButton` — добавлен контрастный стиль для
  `QMessageBox`/`QDialog`.
- Меры PBIX собираются по всем таблицам модели, включая скрытые: мера больше не пропадает
  из «Мер» и из lineage, если закреплена за скрытой таблицей. У такой меры «№ таблицы» = «—»,
  а зависимости (`M…`, `A…`, `S…`) продолжают разрешаться.
- `.pbit`, в котором `Layout` лежит в папке `Report` (новые версии Power BI Desktop),
  открывается: `Layout` и `DataModelSchema` ищутся и в корне, и во вложенных папках архива.

### Ограничения

- PBIX читается без слоя отчёта: визуалы, страницы и условное форматирование недоступны.
- Строки данных (VertiPaq) в v2.2.0 не выгружаются — только метаданные модели.
- `.abf` и `.xlsx` (PowerPivot) не поддерживаются.
- Read-only: файлы не изменяются и не перепаковываются.

## [2.1.0] — 2026-07-12

### Добавлено

- **Горячие клавиши** (задача 2.1):
  - `Ctrl+O` — открыть диалог выбора PBIT файла
  - `Ctrl+S` — выгрузить данные в Excel
  - `Ctrl+H` — открыть справку
  - `Ctrl+Q` — выйти из приложения

- **Drag-and-drop** (задача 2.2):
  - Перетаскивание .pbit файлов из проводника в окно приложения
  - Автоматический выбор файла при drop

- **Поиск по таблицам** (задача 2.3):
  - Строка поиска над каждой таблицей вкладки "Результаты парсинга"
  - Фильтрация по содержимому любой колонки
  - Кнопки "Найти" и "Сброс"
  - Поддержка Enter для быстрого поиска

- **QSS-стили** (задача 2.4):
  - Вынесены все inline-стили в `_work/pbi_modules/styles.qss`
  - Использование objectName для привязки стилей к виджетам
  - Централизованное управление внешним видом приложения

- **Вкладка "Схема PBIT"**:
  - Справочная документация по структуре DataModelSchema и Layout
  - Описание всех ключей, типов данных и иерархии

- **Обновлена справка**:
  - Добавлено описание перетаскивания файлов
  - Добавлено описание поиска по таблицам
  - Обновлены горячие клавиши (Ctrl+S — выгрузка в Excel)
  - Обновлена версия до 2.1

### Изменено

- Удалены emoji-иконки из кнопок (стилизуются через QSS)
- Кнопки используют objectName вместо inline setStyleSheet
- Инициализация `_original_dfs` через `__init__` вместо `hasattr()`
- Упрощена логика проверки наличия `_original_dfs`

### Исправлено

- `_original_dfs` теперь инициализируется в `__init__` как пустой dict
- Убраны дублирующиеся проверки `hasattr(self, '_original_dfs')`
